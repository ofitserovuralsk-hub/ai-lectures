# ai-lectures

Статический сайт-портфолио: лекции и практикумы по применению ИИ для госслужащих Казахстана (акиматы, маслихаты, колледжи ТиПО). Автор — Сергей Офицеров, город Уральск (ЗКО), цель — масштабирование практики на республиканский уровень (в т.ч. заявка в Академию госуправления при Президенте РК).

Чисто статический HTML/CSS/JS, без сборки и фреймворков. Открывается как файлы или через любой статический хостинг.

## Ключевые конвенции (важно перед правками)

**Двуязычность KK/RU.** Всё содержимое дублируется парой спанов, переключение — через `data-lang` на `<body>` и CSS `display:none`:
```html
<span class="lang-kk">...текст на казахском...</span>
<span class="lang-ru">...текст на русском...</span>
```
```css
body[data-lang="kk"] .lang-ru { display: none !important; }
body[data-lang="ru"] .lang-kk { display: none !important; }
```
По умолчанию — казахский (`data-lang="kk"`).

**Язык — общий для всех страниц.** `assets/js/main.js`:
- `setLanguage(lang)` — канонический источник истины. Ставит `data-lang` на body, `document.documentElement.lang`, красит кнопки ҚАЗ/RU, сохраняет выбор в `localStorage.portal_lang`, диспатчит `window` событие `languageChanged`.
- `copyPrompt(button)` — копирует текст промпта в буфер (ищет `.prompt-box`/`.prompt-card` → `.prompt-code`/`code`), чистит служебные подписи регэкспом.
- Подключается на каждой странице: `<script src="assets/js/main.js">` (для `lectures/*.html` — `../assets/js/main.js`).
- **Не плодить локальные копии `setLanguage`.** Если странице нужно что-то доделать при смене языка (обновить подписи графика Chart.js, сменить `<title>`) — вешать `window.addEventListener('languageChanged', e => {...})`, а не переопределять функцию. Образец — конец `lectures/ai-basics-gov.html` и `lectures/maslikhat-ai.html`.
- Ключ `localStorage` только один — `portal_lang`. (Раньше `ai-college-directors.html`/`maslikhat-ai.html` использовали свой `preferred_lang`, из-за чего язык слетал при переходе между страницами — это пофикшено, не возвращать.)

**Стили лекций.** Общее — в `assets/css/lecture.css` (переменные `--primary/--accent/--tech/--danger/--bg`, `.card`, `.chart-container`, `.prompt-code`). В `<style>` конкретной лекции должно оставаться только уникальное — обычно один `.gradient-header{background:...}` под тему лекции (у каждой лекции свой градиент шапки — это осознанно, не унифицировать).

**Chart.js** — подключать только если на странице реально есть `<canvas>`/`new Chart(...)`, и только локально: `<script src="../assets/js/chart.min.js"></script>`. Сейчас используется только в `ai-basics-gov.html` и `maslikhat-ai.html`; на остальных лекциях убран как мёртвый вес.

**Никаких внешних CDN в `<head>`.** Сайт должен открываться в закрытых сетях госорганов, поэтому Tailwind, шрифты и Chart.js лежат локально. Единственная оставшаяся внешняя зависимость — iframe-эмбед Instagram Reels на `videos.html`: если он заблокирован, карточка остаётся с текстом и ссылкой, вёрстка не ломается. Не возвращать `cdn.tailwindcss.com`, `fonts.googleapis.com` и `cdn.jsdelivr.net` в разметку.

**Порядок подключения стилей важен.** `tailwind.css` подключается ПОСЛЕДНИМ в `<head>` — после `lecture.css` и локального `<style>`. Так было и с Play CDN (он дописывал свой `<style>` в конец head), и на этом держится вёрстка: например `.card` в `lecture.css` задаёт `background:white`, и только более поздний `bg-amber-50/40` из Tailwind позволяет подкрасить карточку. Перенесёте `tailwind.css` выше — часть фонов "побелеет".

**Верхняя навигация лекций** — везде липкая: `sticky top-0 z-50`, `py-3`.

**Якоря и липкая шапка.** Шапка `sticky top-0`, поэтому обычный переход по `#hash` прячет начало блока под ней. Всё делает `scrollToAnchor()` в `assets/js/main.js`: высота шапки считается на лету (она разная на телефоне и десктопе), клики по якорям текущей страницы перехватываются, переход с якорем с другой страницы отрабатывает после отрисовки. Используются два якоря: `#lectures` на `index.html` (каталог лекций — туда ведёт пункт меню «Главная (Лекции)» и кнопки «Вернуться к каталогу» из лекций) и `#academy-course` на `videos.html` (карточка курса в Академии).

**Кнопка «наверх».** Стоит на всех девяти страницах в `lectures/`. Подключается сама везде, где есть `<button type="button" id="backToTop" class="back-to-top">` — логика в `initBackToTop()` (`main.js`), стили в `lecture.css`. Появляется после 400px прокрутки, `aria-label` переключается вместе с языком. На `index.html`, `videos.html` и `o-lektore.html` её нет — эти страницы короче; если понадобится, достаточно вставить ту же разметку перед подключением `main.js`.

В стилях обязателен `appearance: none`: preflight из `tailwind.css` ставит кнопкам `-webkit-appearance: button`, и с нативной отрисовкой браузер игнорирует `background-color` — фон пропадает.

**Прокрутка — только через `scrollToY()`** (`main.js`). Она уважает `prefers-reduced-motion` и подстраховывает `behavior:'smooth'`: если через 400 мс страница не сдвинулась (встроенные браузеры и вебвью иногда молча игнорируют плавную прокрутку), доезжает мгновенно. Не вызывать `window.scrollTo({behavior:'smooth'})` напрямую — кнопка будет выглядеть сломанной там, где анимация не поддерживается.

## Пересборка tailwind.css

`assets/css/tailwind.css` — это разовая выгрузка того CSS, который Play CDN генерировал в браузере. Он покрывает только те классы, которые были в разметке на момент сборки. **Если вы добавили в HTML новый Tailwind-класс (например `bg-emerald-200`), он не заработает, пока файл не пересобран.**

Как пересобрать:

1. Сделать временную страницу, куда сложено содержимое `<body>` всех 12 файлов (вместе со значением `class` самого `<body>` — иначе классы вроде `antialiased` и `min-h-screen` потеряются), и подключить в её `<head>` `https://cdn.tailwindcss.com`.
2. Открыть её в браузере, дать CDN отработать и забрать содержимое сгенерированного `<style>` — это и есть готовый CSS.
3. Положить его в `assets/css/tailwind.css`, временную страницу удалить.

Проверить полноту покрытия можно, сравнив все значения `class="..."` в HTML (плюс классы, которые скрипты добавляют через `classList.add`/`.className` — например `bg-teal-500` в `copyPrompt()`) с селекторами в `tailwind.css`. Собственные классы проекта (`card`, `lang-kk`, `gradient-header`, `prompt-card`, `reel-card`, `video-card`, `lecture-card`, `video-player`) в `tailwind.css` отсутствуют штатно — они либо описаны в `lecture.css`/локальных `<style>`, либо служат только зацепками для JS.

## Локальный запуск / предпросмотр

Открывать файлы напрямую (`file://`) в браузере — с ограничениями (некоторые встроенные превью-инструменты рендерят `file://` как статический снимок без относительных путей). Правильный способ — поднять локальный сервер:

```bash
python -m http.server 8080
```

(уже настроено как конфигурация `static-site` в `.claude/launch.json` — в Claude Code это `preview_start` с `name: "static-site"`), затем открыть `http://localhost:8080/index.html`.

## Как пользоваться этим README вместо сканирования проекта

Все 8 файлов в `lectures/` — самостоятельные лендинги с уникальным контентом (кейсы, промпты, графики), но **одинаковой механикой** (язык, стили, навигация — см. конвенции выше). Если задача касается контента конкретной лекции — читать этот один файл. Если задача касается общего поведения (язык, стили, навигация, шапка/подвал) — достаточно `assets/js/main.js`, `assets/css/lecture.css` и одного файла-примера (`ai-basics-gov.html` как самый "чистый" эталон паттерна). Полный обход всех 7 лекций нужен только если меняется что-то, что реально продублировано в каждой (например, структура шапки).
